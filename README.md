# RYOSEI GALAXY

RYOSEIWORLD合同会社のAI組織を紹介する単一HTMLページ（`index.html` 1ファイル完結、外部CSS/JSなし、Google Fontsのみ使用）。

- 内容: ヒーロー / 組織図（各部署=AIエージェント、稼働状況ラベル付き） / 動き方3ステップ / プロモ動画枠 / フッター
- デザイン: 黒ベース＋白文字＋金アクセント（#f0c060）。見出しはZen Old Mincho。レスポンシブ対応（390px幅で横スクロールなし）。
- プロモ動画: `promo.mp4` をこのディレクトリに置くと `#promo` セクションで再生される。無い場合は「動画準備中」表示。
- スクリーンショット: `shots/desktop.png`（1280幅）, `shots/mobile.png`（390幅）
